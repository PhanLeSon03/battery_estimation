Project Folder Organization

Training results for the Transformer and CNN-based models are stored in the checkpoints_clf folder.
Each subfolder in checkpoints contains the results from a separate training section/version,
starting with V1 and continuing with V2, V3, and so on.

Early-stopping results are stored in the checkpoints_es_bml folder. This folder follows the
same structure as checkpoints, but start from V3.

The predict_file folder stores the prediction outputs for each dataset. Its structure also
matches the versioned layout used above, with folders such as V1, V2, and later versions.
